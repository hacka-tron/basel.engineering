Haiku streaming remains blocked by the account first-time-use form.
- **Phase 2 caches:** API queries use an `EmbeddingCache` contract backed by Redis. Questions are whitespace/case normalized before embedding; a SHA-256 key includes the embedding model identity. Packed 512-float vectors expire after 7 days. The worker uses `RetrievalCache` and `ChunkCache` contracts backed by Redis: retrieval results are scoped by corpus, corpus version, model, and query vector (1-hour TTL); chunk text/metadata use chunk IDs (1-day TTL). A changed-document ingest bumps `corpus:ver:{corpus}` after the DB commit. The `AnswerCache` contract has a Redis Search vector implementation (24-hour TTL, cosine similarity >=0.95), scoped by corpus, version, and model. A hit replays retrieval plus answer, logs `answer_hit`, and skips the worker and LLM. Cache hits appear in stage events. A real local Redis/MySQL endpoint repeat test passes; concurrent same-question LLM deduplication has not been added.
- **Phase 2 usage limits:** `RateLimiter` and `DailyBudget` contracts have atomic Redis script implementations. Each salted client-IP hash gets 10 questions per 10 minutes; forwarded IP is considered only from configured trusted proxy CIDRs. A UTC daily cap defaults to 100 generated answers. Answer-cache hits do not reserve a generation slot. At the cap, retrieval still completes and returns `done.mode="retrieval_only"` with source snippets and no LLM call; the frontend shows those snippets and a friendly retry countdown on rate limits. Production must set a stable private `GLASSBOX_IP_HASH_SALT` and trusted proxy CIDRs.
- **Phase 2 retrieval evaluation harness:** `eval/questions.yaml` has 30 public-safe questions; `eval/run_eval.py` measures recall@5 and MRR through the real Redis vector-search path and checks a model/index/content-specific baseline. ## Target architecture (full detail in docs/DESIGN.md)

Browser → Cloudflare (TLS/proxy) → Traefik on a single EC2 `t4g.small` (k3s) → FastAPI `api` + `retrieval-worker` (KEDA-scaled) ↔ Redis (cache/queue/vector index) ↔ RDS MySQL (source of truth) → Amazon Bedrock (embeddings + LLM).
