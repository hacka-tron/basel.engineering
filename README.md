# basel.engineering

[Visit the site](https://basel.engineering)

Hi, I'm Basel. I built this site to give my work a home and to make my portfolio a little more fun to explore. Instead of only reading about my background and projects, you can ask questions about them. You can also ask how the site itself works. It looks through documents I've put together, answers with sources, and shows you the steps it took along the way.

I started Glassbox because I wanted to learn by building something real. It gave me a chance to get hands-on with retrieval-augmented generation (RAG), embeddings, and language models, as well as the infrastructure behind them: k3s, Kubernetes, Terraform, and AWS. I wanted to understand how those pieces fit together from the first question to the final answer, including the messy parts that don't show up in a tutorial.

Under the hood, a React frontend talks to a Python API. Redis helps find relevant material and move work through the system, MySQL stores the documents, and Amazon Bedrock generates the answer. The site is also a place for me to share what I've built and what I'm learning next.
