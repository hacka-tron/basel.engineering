# Individual Projects

## Goal Buddy

[Goal Buddy](https://github.com/hacka-tron/goalbuddy/) is a production-scale social accountability platform designed to gamify personal goal setting through real-time community interaction. Basel architected the multiplatform mobile application using React Native, Expo, and Zustand for optimized client-side state management, backed by a Node.js API layer. He also built a Retrieval-Augmented Generation (RAG) solution that enriches AI-generated coaching responses with curated educational resources and goal-specific best practices, improving the relevance and reliability of user recommendations — an early, direct precursor to the RAG techniques used in this site (Glassbox) itself.

## CryptoKing

[CryptoKing](https://github.com/hacka-tron/CryptoKing) is a responsive, full-stack mock cryptocurrency trading platform built on the MEAN stack, processing real-time asset price tracking and portfolio management. Basel architected a serverless backend deployment on AWS, using Lambda functions for scalable, event-driven API logic and S3 for optimized static frontend hosting. He also designed and implemented a relational leaderboard system that dynamically aggregates and renders user investment statistics and portfolio performance metrics.
